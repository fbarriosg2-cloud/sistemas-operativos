Introducción

Un sistema operativo (SO) es el software fundamental que administra los recursos de una computadora y permite que las aplicaciones se comuniquen con el hardware. Actúa como intermediario entre el usuario, los programas y los componentes físicos.

Objetivo del proyecto: explicar los conceptos esenciales de los sistemas operativos, su desarrollo histórico, sus componentes y algunos mecanismos para administrar procesos y memoria.

Orígenes y breve historia de los sistemas operativos

En las primeras computadoras, los programas se ejecutaban directamente sobre el hardware y la operación requería intervención manual. Con el crecimiento de la computación surgió la necesidad de automatizar tareas y compartir los recursos.

  • Décadas de 1940 y 1950: operación manual y primeros sistemas de procesamiento por lotes.
  • Décadas de 1960 y 1970: multiprogramación, tiempo compartido y sistemas multiusuario.
  • Décadas de 1980 y 1990: expansión de computadoras personales e interfaces gráficas.
  • Décadas de 2000 y 2010: virtualización, computación en la nube y teléfonos inteligentes.
  • Actualidad: sistemas conectados, distribuidos, móviles, embebidos y orientados a servicios.

Hardware y software de la computadora

Hardware

Elementos físicos: CPU, memoria RAM, almacenamiento SSD/HDD, placa base, pantalla, teclado y dispositivos de red.

Software

Programas e instrucciones: sistema operativo, controladores, utilidades y aplicaciones de usuario.

El sistema operativo coordina el acceso al hardware mediante controladores (drivers), administra la memoria y ofrece servicios para que las aplicaciones funcionen sin controlar directamente cada dispositivo.

Ecosistema del sistema operativo

El ecosistema está formado por el núcleo (kernel), servicios del sistema, controladores, bibliotecas, interfaz de usuario, aplicaciones, usuarios y dispositivos conectados.

Usuario

Interactúa mediante una interfaz gráfica o terminal.

Aplicaciones

Solicitan servicios para realizar tareas.

Kernel

Gestiona CPU, memoria y operaciones privilegiadas.

Hardware

Ejecuta instrucciones y almacena o transmite datos.

Componentes principales del sistema operativo

  • Gestión de procesos: crea, planifica, sincroniza y finaliza procesos.
  • Gestión de memoria: asigna y libera memoria; puede utilizar memoria virtual.
  • Sistema de archivos: organiza archivos, carpetas y permisos.
  • Gestión de dispositivos: coordina periféricos mediante controladores.
  • Seguridad: autentica usuarios y controla el acceso a recursos.
  • Interfaz y llamadas al sistema: permiten la interacción y el acceso controlado a servicios del kernel.
  • Redes: facilita la comunicación entre equipos y servicios.

Algoritmo del banquero

El algoritmo del banquero es una técnica de prevención de interbloqueos. Antes de conceder una solicitud, analiza si la asignación dejaría al sistema en un estado seguro: debe existir al menos un orden en el que todos los procesos puedan terminar con los recursos disponibles y los que vayan liberando.

La siguiente demostración usa una instancia clásica con cinco procesos y tres tipos de recursos (A, B y C).

Disponible = [3, 3, 2]

Asignación:
P0 [0, 1, 0]   P1 [2, 0, 0]   P2 [3, 0, 2]
P3 [2, 1, 1]   P4 [0, 0, 2]

Necesidad = Máximo - Asignación
P0 [7, 4, 3]   P1 [1, 2, 2]   P2 [6, 0, 0]
P3 [0, 1, 1]   P4 [4, 3, 1]
Pulsa el botón para ejecutar la comprobación.

Ejemplo de código Python

def estado_seguro(disponible, asignacion, necesidad):
    n = len(asignacion)
    trabajo = disponible[:]
    terminado = [False] * n
    secuencia = []

    progreso = True
    while progreso:
        progreso = False
        for i in range(n):
            if not terminado[i] and all(
                necesidad[i][j] <= trabajo[j]
                for j in range(len(disponible))
            ):
                trabajo = [
                    trabajo[j] + asignacion[i][j]
                    for j in range(len(disponible))
                ]
                terminado[i] = True
                secuencia.append(f"P{i}")
                progreso = True

    return (all(terminado), secuencia)

Procesos e hilos

Proceso

Programa en ejecución con su propio espacio de direcciones y recursos asignados. El sistema operativo planifica su uso del procesador.

Hilo (thread)

Unidad de ejecución dentro de un proceso. Los hilos del mismo proceso comparten memoria y recursos, aunque cada uno tiene su propio contexto de ejecución.

Los hilos pueden mejorar la capacidad de respuesta y permitir concurrencia. Requieren sincronización para evitar condiciones de carrera cuando acceden a datos compartidos.

Comentario personal y conclusión

Considero que estudiar los sistemas operativos es esencial en Ingeniería en Sistemas, porque permite comprender cómo se administran los recursos que hacen posible ejecutar programas y ofrecer servicios. Conocer sus componentes, procesos y mecanismos de seguridad ayuda a tomar mejores decisiones al desarrollar y mantener soluciones informáticas.

En conclusión, el sistema operativo es la base que conecta el hardware con el software. Su evolución ha permitido computadoras más accesibles, conectadas, seguras y capaces de atender múltiples tareas.
