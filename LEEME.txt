WEBSITE SISTEMAS OPERATIVOS
============================

CONTENIDO DEL PAQUETE
- index.html: sitio web completo (HTML5, CSS3 y JavaScript).
- algoritmo_banquero.py: ejemplo ejecutable del algoritmo del banquero en Python 3.
- LEEME.txt: estas instrucciones.

PUBLICAR EN GITHUB PAGES
1. Extrae este ZIP en tu teléfono o computadora.
2. Entra al repositorio GitHub: https://github.com/fbarriosg2-cloud/sistemas-operativos
3. Sube los TRES archivos extraídos a la raíz del repositorio (no subas el ZIP).
4. Confirma los cambios con Commit changes.
5. En Settings > Pages, configura:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
   Pulsa Save.
6. Espera a que termine la publicación. El enlace esperado es:
   https://fbarriosg2-cloud.github.io/sistemas-operativos/

IMPORTANTE
- El archivo index.html debe estar directamente en la raíz del repositorio.
- Si el repositorio utiliza otra rama distinta de main, selecciona la rama que contiene index.html.
- GitHub Pages publica el sitio estático. El archivo Python se ofrece como código descargable/consultable; no se ejecuta en el navegador.
- Antes de entregar, completa los datos personales o académicos que solicite tu docente.
